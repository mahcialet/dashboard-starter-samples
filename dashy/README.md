# Dashyサンプル

多機能スタートページDashyのサンプルです。テーマ、サービスの定期ステータスチェック、RSSウィジェット、UIエディタを試せます。

## 起動

```bash
docker compose up -d
```

<http://localhost:8080> を開きます。別ポートなら `PORT=8081 docker compose up -d` とします。初回起動ではフロントエンドの準備に少し時間がかかることがあります。

## 主な構成

- `user-data/conf.yml`: ページ情報、テーマ、セクション、リンク、RSSウィジェット
- `appConfig.statusCheck`: リンク先の60秒間隔のステータス確認
- 画面右上の設定メニュー: テーマ変更と設定エディタ

UIから設定を保存すると `user-data/conf.yml` が更新されます。サンプルは認証を有効にしていないため、インターネットへそのまま公開しないでください。
