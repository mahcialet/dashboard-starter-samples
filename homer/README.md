# Homerサンプル

単一のYAMLから静的なスタートページを生成するHomerのサンプルです。非常に軽量で、リンクと見た目をGitで管理したい場合に向いています。ダッシュボード製品と運用資料の初期リンクを含みます。

## 起動

```bash
docker compose up -d
```

<http://localhost:8080> を開きます。別ポートなら `PORT=8081 docker compose up -d` とします。データベース、ログイン、サーバー側APIはありません。

## 主な構成

- `assets/config.yml`: タイトル、テーマ、メッセージ、ナビゲーション、リンク集
- `services`: ダッシュボード製品と運用資料のグループ
- `defaults`: カード表示と新しいタブで開く既定動作

設定変更はブラウザの再読み込みで反映されます。機密情報をYAMLへ記述すると、そのままブラウザへ配信されるため、APIキーやパスワードは保存しないでください。
